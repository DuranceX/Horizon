## [Anthropic 主张对开放权重模型强制安全测试而非禁令](https://www.anthropic.com/news/position-open-weights-models) ⭐️ 8.0/10

Anthropic 发布了一份政策立场，声称自己从未主张禁止开放权重模型，而是认为所有能力足够强的模型（无论开放还是封闭）都应接受强制性的安全测试。文章还重申支持打击向中国走私芯片等措施。 作为领先的 AI 实验室之一，Anthropic 的监管立场可能影响各国政府如何对待开放权重模型，而许多开发者依赖这类可自由下载、可定制的 AI。批评者担心该提议可能以安全为名巩固行业巨头地位并限制开源竞争。 评论者指出，强制性安全测试留下了诸多未解问题：谁来主持测试、成本有多高、主持方是否可以拒绝某些人参与，这些都可能使其实际上等同于一种禁令。还有人指出明显的矛盾：Anthropic 的 CEO 一方面说禁令无效，另一方面却支持禁止向中国销售芯片。

hackernews · surprisetalk · 7月27日 22:03 · [社区讨论](https://news.ycombinator.com/item?id=49076057)

**背景**: 开放权重模型是指其核心参数被公开发布的 AI 模型，任何人都可以下载、检查、修改并在自己的基础设施上运行。监管俘获指的是监管最终服务于大型在位企业而非公众利益的情形，例如通过设置只有资金雄厚的公司才能满足的合规负担来实现。在 AI 政策辩论中，批评者认为，把先进 AI 描述为过于危险而不宜开放发布，可能导致只有 Anthropic 或 OpenAI 这类大型实验室才能满足的规则。

## [SGLang v0.5.16 新增 DSpark 推测解码与 975B 多模态 MoE 支持](https://github.com/sgl-project/sglang/releases/tag/v0.5.16) ⭐️ 7.0/10

SGLang v0.5.16 发布，包含来自 169 位贡献者的 574 个 PR，推出了 DSpark——一种基于置信度的推测解码算法，它根据草稿自身的置信度来动态确定每个验证窗口的大小，在 DeepSeek-V4-Pro 上（TP8、B300）以约 5 的接受长度达到 383.7 tok/s。该版本还新增了对 Inkling 的首日支持，这是一个 975B 参数的多模态 MoE 模型，具备 100 万 token 上下文，混合了滑动窗口、全注意力和 Mamba2 线性注意力，并加入了 NVFP4 MoE。 SGLang 是一个被广泛使用的开源 LLM 推理框架，因此这次同时带来新型推测解码算法与超大规模多模态 MoE 模型支持的发布，直接惠及那些需要高效部署前沿模型的团队。其内存优化（如每 rank KV 内存降低约 74%、推测缓存缩小 6.4 倍）降低了大规模运行长上下文和推测解码任务的硬件成本。 该版本将 UnifiedRadixTree 设为 SWA、Mamba 和 DSA 模型的默认选项，新增了 GLM-5.2 的 DSA 缓存层切分（每 rank KV 内存降低约 74%）和 ReplaySSM Ring Spec-Verify（每 GPU 从 11.5 GB 降至 1.8 GB），并实现了 Blackwell SM100 上首个正确的 KDA MTP 路径。同时移除了一些实验性路径：QServe（QoQ）W4A8 和 FBGEMM FP8 被删除，由于内置 JIT 内核和 cutlass fp4 后端被移除，NVFP4 GEMM 现在需要 FlashInfer。

github · Qiaolin-Yu · 7月25日 00:13

**背景**: 推测解码通过使用一个更廉价的草稿模型提前猜测多个 token，再用完整模型并行验证并接受正确的部分，从而加速 LLM 推理。混合专家（MoE）模型会把每个 token 路由到一部分专家子网络，因此一个 975B 参数的模型每个 token 只激活部分权重；而 NVFP4 是 NVIDIA 的 4 位浮点格式，Blackwell GPU 通过硬件加速它来提升 MoE 推理效率。Mamba2 是一种线性注意力机制，其计算量随序列长度线性增长而非二次方增长；MTP（多 token 预测）让模型在一次前向传播中预测多个未来 token，是一种内置的推测解码形式。

## [以 O(N) 线性时间复杂度运行的 N 体引力模拟](https://www.youtube.com/watch?v=FhMftauQZqU) ⭐️ 6.0/10

一段 YouTube 视频展示了一种能达到线性 O(N) 时间复杂度的 N 体引力模拟方法，而不是逐对计算所有相互作用的朴素 O(N²) 成本。它演示了如何用近似技术把引力模拟扩展到数量大得多的天体。 把 N 体模拟从 O(N²) 降到 O(N)，使得模拟数百万粒子成为可能，这对天体物理学、星系形成研究以及任何依赖大规模粒子相互作用的领域都很重要。更快的算法直接意味着可以做更大规模的模拟，或降低计算成本。 线性时间的 N 体方法通常依赖空间近似方案，例如使用四叉树/八叉树的 Barnes-Hut 算法（O(N log N)），或经典的快速多极子方法（FMM），后者通过将远处天体分组并近似其整体影响来实现真正的 O(N)。这些方法用少量可控的精度损失换取巨大的速度提升。

rss · Lobsters · 7月27日 08:45

**背景**: N 体问题涉及计算 N 个质量之间的引力，其中每个天体都会吸引其他所有天体。直接计算所有成对相互作用的成本为 O(N²)，随着 N 增大会变得极其昂贵。Barnes-Hut 模拟（由 Joshua Barnes 和 Piet Hut 提出）使用树结构把远处的天体群近似为单个点，而最初为引力 N 体相互作用发明的快速多极子方法（FMM）可以把成本降到 O(N)，并广泛应用于声学、电磁学和流体动力学。
