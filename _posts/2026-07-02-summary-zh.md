## [首个从头构建的合成细胞实现生长与分裂](https://www.quantamagazine.org/for-the-first-time-a-cell-built-from-scratch-grows-and-divides-20260701/) ⭐️ 8.0/10

由 Kate Adamala 领导的研究团队报告了名为 SpudCells 的成果，据称这是首个能够同时生长和分裂的从头构建细胞，团队通过放弃细胞骨架、而非像自然细胞那样重组细胞骨架，解决了细胞分裂这一难题。 在完全合成的细胞中实现自我复制将是合成生物学的一个重大里程碑，因为细胞分裂长期以来一直是将工程细胞与真正的生命系统区分开来的关键障碍。 该主张仍存在争议且未经审查：据报道，这份长达 190 页的手稿在一位审稿人认为 SpudCells“不是真正的生物学”后被《Cell》期刊拒稿，而 Adamala 在将其上传到 bioRxiv 预印本服务器之前就以禁发期形式发给了记者，因绕过同行评审而招致批评。

hackernews · defrost · 7月1日 14:20 · [社区讨论](https://news.ycombinator.com/item?id=48747304)

**背景**: 合成生物学旨在用基本的分子组件构建活细胞，此前的研究已经能够为合成细胞提供养分、使其生长并复制其 DNA。剩下的障碍是细胞分裂，在自然细胞中，这依赖于重组细胞骨架——一个提供结构支撑、帮助细胞分裂并将 DNA 减半的蛋白纤维网络。Adamala 团队在该领域也以早期工作而闻名，包括出于安全担忧而终止了一项拟议中的右手性蛋白质（“镜像生命”）实验。

## [Cloudflare 推出基于 x402 的按请求收费货币化网关](https://blog.cloudflare.com/monetization-gateway/) ⭐️ 8.0/10

Cloudflare 推出了一个基于 x402 协议的货币化网关，让运营商可以对访问其网络后端任意资源的 AI 智能体和客户端按请求收费。当请求到达时，服务器可以返回 HTTP 402 状态码，要求先完成付款（通常是稳定币），然后再授予访问权限。 作为主要的 Web 基础设施提供商，Cloudflare 将按请求付费推向主流，标志着行业正认真推动由智能体驱动的微支付，以及在 AI 机器人流量上升背景下的一种新内容变现模式。它可能让运营商有办法从自动化客户端处收回托管成本，并让 AI 智能体自主为其消耗的资源付费。 x402 协议重新启用了长期闲置的 HTTP 402“需要付款”状态码，并使用稳定币而非传统银行卡渠道来结算付款。一个关键的未决问题是，这一模式解决了向自动化客户端收费的问题，但本身并未解决运营商如何在区分机器人的同时为人类用户保留免费访问。

hackernews · soheilpro · 7月1日 13:59 · [社区讨论](https://news.ycombinator.com/item?id=48746914)

**背景**: HTTP 402“需要付款”是原始 HTTP 规范中预留但从未被广泛实现的状态码，而 x402 是最近一个终于将其用于机器对机器支付的协议。能够自主浏览和操作网络的 AI 智能体的兴起，重新点燃了人们对微支付的兴趣，从而让智能体可以为 API 调用或内容支付小额费用，而无需人类去管理账户和 API 密钥。

**社区讨论**: 讨论对智能体自主付费访问这一期待已久的愿景充满热情，但也提出了实质性担忧：一位评论者认为它没能解决核心问题，即在机器人流量推高托管成本的同时如何为人类保留免费体验；另一位指出稳定币付款在开票和增值税方面存在法律与税务复杂性；还有人担心它可能催生一种由低质量变现内容组成的新垃圾信息经济。

## [FUSE readdir 缓存越界写漏洞可让普通用户提权至 root（CVE-2026-31694）](https://cyberstan.co.uk/fuse-readdir-oob/) ⭐️ 8.0/10

一篇技术分析文章详细剖析了 CVE-2026-31694，这是 Linux 内核 FUSE readdir 缓存中的一个越界写漏洞，普通本地用户可借此将权限提升至 root。 在广泛使用的内核子系统中实现本地提权至 root 是一个严重威胁，因为 FUSE 在许多 Linux 发行版上对普通用户开放，这扩大了任何拥有本地访问权限者的攻击面。 该漏洞源于 FUSE readdir 缓存路径中的越界写，该路径负责处理由用户态文件系统实现返回的目录项数据，文章详细讲解了如何将这种内存破坏转化为可靠的 root 提权利用。

rss · Lobsters · 7月2日 00:36

**背景**: FUSE（用户空间文件系统）是 Linux 内核的一项功能，允许开发者在用户态程序中而非内核代码里实现完整的文件系统，常被 sshfs 以及各类容器和云存储系统使用。由于 FUSE 可供普通用户使用，内核在处理跨越用户态与内核边界数据时的缺陷尤其危险。readdir 操作用于列出目录内容，内核会缓存这些目录项；当数据被写到已分配缓冲区的边界之外时就会发生越界写，从而破坏相邻内存。攻击者通常能将这类内存破坏塑造为任意代码执行或权限提升。

## [FFmpeg 9.1 带来大幅改进的原生 AAC 编码器](https://hydrogenaudio.org/index.php/topic,129691.0.html) ⭐️ 7.0/10
